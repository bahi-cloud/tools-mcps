# G4F OpenAI Gateway

بوابة (Gateway) متوافقة مع OpenAI API مبنية على FastAPI و g4f، مع نظام وكيل ذكي يدعم الأدوات (Tools)، الفحص الصحي للنماذج، وكشف الوعود الفارغة. الوكيل متكامل مع باك اند خارجي (`ayb-bh92-tools`) يوفر أكثر من **120 أداة** تشمل إنشاء المستندات، تحرير الفيديو، البحث، والتكامل مع تطبيقات خارجية عبر Composio.

## 📌 المميزات الأساسية

- ✅ نقطة نهاية `/v1/chat/completions` متوافقة مع OpenAI.
- ✅ دعم التدفق (SSE Streaming).
- ✅ اكتشاف ديناميكي للنماذج مع فحص صحي دوري (يتم فحص 94 نموذجاً).
- ✅ تطبيع استدعاءات الأدوات وإصلاح JSON المكسور تلقائياً.
- ✅ حلقة تنفيذ ذكية مع كشف الوعود الفارغة (Hedging Detection) وبروتوكول JSON صارم.
- ✅ مصادقة عبر API Key.
- ✅ **أداة عامة (`call_tool`)** لتغطية جميع أدوات الباك اند الخارجي دون الحاجة لتسجيلها يدوياً.

## 🧰 الأدوات المتاحة (أكثر من 120 أداة)

الوكيل متصل بخادم أدوات خارجي (`https://ayb-bh92-tools.hf.space/call`) يوفر:

| الفئة | الأدوات | العدد |
|-------|----------|-------|
| **المستندات** | إنشاء وقراءة PDF، DOCX، PPTX، XLSX | 7 |
| **تحرير الفيديو/الصوت** | قص، دمج، إضافة ترجمات، تحويل، استخراج صوت، وغيرها (عبر MCP) | 100+ |
| **البحث والتصفح** | Firecrawl Search & Scrape | 2 |
| **التوثيق** | Context7 للبحث في توثيق المكتبات | 2 |
| **التكامل الخارجي** | Composio (Gmail, Slack, GitHub, Drive, وغيرها) | 7 |
| **التحويلات** | Markdown إلى HTML | 1 |
| **الوسائط** | تحميل ملفات، كتابة نصوص | 2 |

> 💡 **ملاحظة:** الوكيل يستخدم أداة `call_tool` لاستدعاء أي من هذه الأدوات عبر الباك اند، مما يلغي الحاجة لتسجيل كل أداة على حدة في `SERVER_TOOLS`.

## ⚙️ المتغيرات البيئية

| المتغير | الوصف | الافتراضي |
|----------|-------|-----------|
| `API_KEY` | مفتاح المصادقة (أضفه كـ Secret) | `change-me` |
| `DEFAULT_MODEL` | النموذج الافتراضي | `gpt-4o-mini` |
| `SCAN_ON_STARTUP` | فحص النماذج عند الإقلاع | `true` |
| `SCAN_INTERVAL_HOURS` | الفاصل بين الفحوصات الدورية | `6` |
| `REQUEST_TIMEOUT` | مهلة الطلب بالثواني | `120` |
| `MAX_TOOL_RETRIES` | أقصى محاولات حلقة الوكيل | `3` |

> 💡 يُنصح بضبط `SCAN_ON_STARTUP=false` على الخطة المجانية لتسريع الإقلاع.
